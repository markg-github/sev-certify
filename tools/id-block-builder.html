SEV-SNP ID Block Builder

Generates a signed ID block and ID auth block for SEV-SNP guest launch. Only an ID key is required; use author-key-enabled=off in QEMU so the firmware ignores the author key fields. Output is base64-encoded for QEMU's id-block= and id-auth= options.

ID Block

All zeros skips the firmware launch-measurement check — sufficient for SVN sensitivity testing.
Upper bound for --guest_svn in key derivation. Set ≥ 1 to enable SVN sensitivity testing (tests values 0..guest_svn).

Guest Policy

64-bit value embedded in the ID block. Must match the policy set at SNP_LAUNCH_START — firmware rejects the launch if they differ.

ID Key

Signs the ID block. ECDSA P-384. The corresponding public key is embedded in the ID auth block. Author key fields in the auth block are zeroed; set author-key-enabled=off in QEMU.
